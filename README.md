Base is an Ethereum Layer-2 blockchain incubated by Coinbase.
It is designed to make on-chain transactions cheaper and faster.
Base is built on Ethereum.
It leverages Ethereum’s security guarantees.
Base uses Optimistic Rollup technology.
It is built using the OP Stack.
The OP Stack was originally developed by Optimism.
Base was publicly announced in February 2023.
Base mainnet went live in August 2023.
Base does not have its own token.
