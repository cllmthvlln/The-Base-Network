Base is an Ethereum Layer-2 blockchain incubated by Coinbase.
It is designed to make on-chain transactions cheaper and faster.
Base is built on Ethereum.
It leverages Ethereum’s security guarantees.
Base uses Optimistic Rollup technology.
It is built using the OP Stack.
The OP Stack was originally developed by Optimism.
Base was publicly announced in February 2023.
Base mainnet went live in August 2023.
Base does not have its own token.
Aerodrome Finance is the largest decentralized exchange (DEX) on Base.
Base’s NFT marketplaces include OpenSea and Magic Eden integrations.
Base’s official bridge allows USDC, ETH, and other ERC‑20s to move securely.
Virtuals Protocol allows AI agents to operate on Base and interact with users.
HeyElsa AI is an AI-driven tool on Base for analysis and on-chain execution.
Base App consolidates wallet, DEX, GameFi, and social tools in one interface.
